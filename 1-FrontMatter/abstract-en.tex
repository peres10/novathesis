{
  The management of internships, dissertations, and engineering projects at the Department of Computer Science (DI) of NOVA School of Science and Technology (FCT)
  currently relies on a legacy platform that is technically obsolete and limited to undergraduate cycles.
  Master's degree processes are instead handled with spreadsheets and informal email exchanges, leading to fragmented data, audit difficulties, and high administrative overhead for coordinators,
  professors, companies, and the secretariat.
  At the same time, the existing platform suffers from UX issues, email deliverability failures, and security vulnerabilities, making incremental evolution unfeasible.
}

{
  This problem is relevant and challenging because internship and dissertation placement are critical process for students' academic paths and for the department's relationship
  with companies.
  The new solution must combine complex functional requirements (automated seriation, multiple user profiles, distinct workflows for different degrees) with demanding
  non-functional requirements (security, auditability, interoperability, usability, and long-term maintainability).
}

{
  This dissertation proposes the design and implementation of a unified web platform for managing proposals and candidacies, built on a layered architecture with a React frontend,
  a backend initially supported by Supabase and later evolved to Spring Boot, and a PostgreSQL database. 
  The work follows an iterative methodology that includes requirements gathering, process (BPMN) and data (ERD) modeling, use case definition, and accelerated prototyping with Vibe Coding tools, 
  followed by refactoring and architectural hardening.
}

{
  The expected outcome is a production-ready platform prototype that centralizes all internship and dissertation processes,
  automated critical tasks (seriation, notification, protocol handling), improves user experience and data quality for all stakeholders, 
  and demonstrates how Vibe Coding tools can be effectively integrated into the development of institutional systems.
}
