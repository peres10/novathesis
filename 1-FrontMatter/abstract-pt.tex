{
  A gestão de estágios, dissertações e projetos de engenharia no Departamento de Informática (DI) da NOVA School of Science and Technology (FCT) depende atualmente 
  de uma plataforma legada, tecnicamente obsoleta. 
  Os processos de mestrado são tratados com folhas de cálculo e trocas de informais de e-mail, originando dados fragmentados, dificuldades de auditoria
  e uma carga administrativa elevada para coordenadores, professores, empresas e secretaria.
  Em paralelo, a plataforma existente sofre de problemas de UX, falhas de entregabilidade de e-mail e vulnerabilidades de segurança, tornando
  inviável a sua evolução incremental.
}

{
  Este problema é relevante e desafiante porque a atribuição de estágios e dissertações é crítica para o percurso académico dos estudantes e para a relação 
  do departamento com as empresas. 
  A nova solução tem de conciliar requisitos funcionais complexos (seriação automática, múltiplos perfis de utilizador, fluxos distintos para diferentes ciclos)
  com requisitos não funcionais exigentes (segurança, auditabilidade, interoperabilidade, usabilidade e manutenção a longo prazo).
}

{
  Esta dissertação propõe o desenho e a implementação de uma plataforma web unificada para gestão de propostas e candidaturas, assente numa arquitetura em camadas,
  com frontend React, backend inicialmente suportado por Supabase e posteriormente evoluído para Spring Boot, e base de dados PostgreSQL.
  O trabalho segue uma metodologia iterativa que inclui levantamento de requisitos, modelação de processos (BPMN) e dados (ERD), definição de casos de uso e prototipagem acelerada
  com ferramentas de \textit{Vibe Coding}, seguida de refatorização para aumentar a robustez e completude da solução.
}

{
  Espera-se como resultado um protótipo de plataforma próximo de produção que centralize os processos de estágios
  e dissertações, automatize tarefas críticas (seriação, notificações, gestão de protocolos), melhore a experiência de utilização
  e a qualidade dos dados para todos os intervenientes, demonstrando como ferramentas de \textit{Vibe Coding} podem ser integradas de forma eficaz no 
  desenvolvimento de sistemas institucionais.
}
